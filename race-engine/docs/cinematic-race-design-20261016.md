# CINEMATIC RACE 3D — 実装指示書・実装記録（2026年10月16日）

## 目的
「予想分析UIの装飾」ではなく、レース映像の実体をアニメ競馬ゲーム風の**オリジナル3Dライブ演出**へアップグレードする。手動の視点切替は廃止し、全頭のシミュレータ位置・着順に追従するオートディレクターが映像を自動的に構成する。特定の既存ゲーム作品の素材・画像・商標・キャラクターは流用しない。

## 絶対不変（計算・馬券予想）
- `core/factors.js`, `core/regression.js`, `core/simulator.js`, `races/*.js` と予想データの**計算と採点は変更しない**。
- `horseProgress(no,clock)`, `LIVE.duration`, `LIVE.clock`, `LIVE.visualTime`, 順位並び替えは従来の共通エンジンから読み取るだけ。演出側で通過・追い越し・着順の結果を作らない。
- 枠番号とJRA騎手帽色は `core/jockey-caps.js` をそのまま利用。馬番・勝負服との混同を起こさない。
- 距離・コースの3D形状は従来どおり模式図。京都芝2000mの実測コース再現や競馬の物理エンジン実装ではない。
- ギャンブルの確率・モデル内勝率は未校正。ゲーム調演出を統計的妥当性や的中保証として使わない。

## フェーズと自動カメラ
| Phase | 進捗 | 構図 | ライブ演出 |
|---|---|---|---|
| GATE IN | 発走前 | ゲートを見渡す低め斜め横 | 日本語字幕・シネマ枠 |
| BREAK AWAY | ～3.5% | ゲートに並走する発走ショット | 芝チップと発走タイトル |
| FULL GALLOP | ～40% | 先頭集団を横から追う | 追走感と競馬場群衆 |
| THE CHASE | ～70% | 馬群と外ラチを俯瞰 | 展開を見やすい大きい構図 |
| FINAL TURN | ～83% | 馬群へ徐々に寄る斜めショット | コーナーの進出感 |
| LAST 400 | ～96.5% | 低い追走、先頭2頭を追う | 流線・馬体強調・VSテロップ |
| TO THE LINE | ゴールまで | 先頭の前方からの正面競り合い | 大きな決着演出 |
| PHOTO FINISH | ゴール後 | 勝馬にピントを合わせる寄りカット | 実シミュレーション順位で勝者、紙吹雪 |

進捗は `clock / duration` から求め、固定的な脚本で**架空の追い抜きは作らない**。カメラは馬群の先頭座標 `path(lead.p)` とレース順に追従する。

## 3Dシーン演出
- `assets/race-cinematics.js` — Three.js専用演出モジュール。汎用コースに奥行きのあるスタンド、屋根、観客の `InstancedMesh`、日差しと縁取り光、細かい芝チップ `InstancedMesh`、先頭争いの発光ストリークを配置。
- 17頭それぞれの根本モデル位置だけを読み、脚元の芝、スピード軌跡、光輪を更新。物理進行・`horseProgress` を書き換えない。
- `assets/horse-anime.js` — 騎手の `rider` 部品をアニメーション用に公開。従来の枠色のヘルメットと馬の専用色を維持。
- `assets/chibi-gallop.js` — 最終直線のみ脚振り幅と騎手の前傾を少し強める**視覚的モーション**。走行速度や順位は一切変えない。
- `renderer.js` — 手動カメラコードを削除。新しい監督モジュールで `desired` と `look` と画角を自動更新。WebGL読込エラー時には従来SVG模式図へフォールバック。

## 放送演出・スマートフォン最適化
- `assets/race-cinematics.css` — 「場面タイトル」「残り直線のスピード線」「先頭2頭のVSテロップ」「勝馬発表」「紙吹雪」。画面に操作を透過させ、再生コントロールを邪魔しない。
- `index.html` — 全レースにシネマCSSと自動監督を読み込む。ブラウザキャッシュによって以前の3D馬を表示しないようにURLバージョンを更新。
- `assets/premium-mobile.js` — 手動カメラの切替ボタンを生成しない。全画面「集中表示」は任意だが、視点切替ではない。
- 画面比率の異なるiPhone/iPad/デスクトップでFOVと字幕サイズを調整。小画面では馬名の文字切れや過度な画面占有を防止。
- CSS `prefers-reduced-motion` に対応。軽量WebGL描画のため観客・芝をインスタンス化し、パーティクル数をスマートフォンで削減する。
- 実レースの録画や公式中継ではなく、仮想レースの演出であることを画面に明記する。

## バージョンと対象
- 共通エンジン `race-engine/index.html` から読み込むので、秋華賞以外の既存レース・以後の新規レースにも反映。
- 旧カメラ「全景／ゲート／追走／馬アップ／ゴール前」のユーザー向けメニューは不要。2DはWebGL障害時の自動フォールバックとして維持。
- パッケージ化されたアニメーション映像ではなく、従来の位置・順位データをリアルタイム描画するブラウザベースのThree.js映像。

## 合格基準
1. `node race-engine/tests/smoke.mjs` が成功。
2. 旧モデル `races/shuka-2026.js` と数理用 `core/factors.js`, `core/regression.js`, `core/simulator.js` のblob SHAが改修前から不変。
3. 秋華賞17頭の乱数seedと採点・出現率が一致。
4. 全8枠のJRA騎手帽色は正しく、勝負服とは独立。
5. 全7つの走行場面とゴールの字幕・先頭争いが、`clock` に追従して表示される。
6. モバイルWebGLではカメラ視点を手で変える必要がない。SVGフォールバックで再生が止まらない。
7. GitHub Actionsで自動テストとPages公開が成功。
8. 実機iPhoneでの音声・フレームレート・描画崩れ・ブラウザコンソールの目視検証は、別途確認対象（CIのみで実機動作を保証しない）。
