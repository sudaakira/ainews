# 宝塚記念2026・共通3Dエンジンのリプレイ

公開先: [3Dリプレイ](../takarazuka-2026-replay.html)

2026年6月14日、阪神11R、芝2200m・Bコース・重。全18頭。
独立した2Dプレーヤーを、既存の `renderer.js` と馬モデル・ギャロップ・5カットのカメラを使う3Dプレーヤーに置き換えた。

## 取得したもの

JRAの公式動画の下部に焼き込まれた馬番マーカーを0.5秒間隔で解析した。
画面上の候補2,640点から、スコア・重複・局所的な移動量の検査を通った2,111点を3D軌跡の入力に使う。
各馬の元ピクセル座標、動画時刻、マッチングスコア、採用・除外の区別をJSONに保持する。

元のGNSS/GPS座標、JRA内部の測位APIは取得していない。マッチングスコアは確率や位置精度の保証ではない。
馬番の重なり・誤読の可能性があり、全サンプルを目視照合したデータではない。

## 座標と補間

- 画像は854×480。左向き・右向きで位置図の軸が反転するため、方向を判定して補正する。
- 位置図の200m表示と映像タイミングから縮尺4.2667px/m、有効開始オフセット7.6秒を**推定**する。表示の遅延・丸めを含むため、測量値ではない。
- 前後の位置は、公式200mラップから求めた先頭の進行距離と、画面上の前後差を組み合わせる。内外の位置は位置図のY座標から復元する。表示側でマーカー位置が整理されている可能性があり、実走ラインの正確な復元とは断定できない。
- 読み取った点は `video-observation`、発走位置は `estimated-start`、公式時計のゴール拘束は `official-finish-clock`。間の動きはPCHIP補間。観測と補間を混同しない。
- 発走直後のマーカー非表示、マーカーの重なり、低スコアで除外した区間は補間。ゴール後の走り抜けは14.5m/sの描画上の仮定。
- 同タイム馬は公式時計の丸め幅内で0.02秒ずつ分け、公式の着順を保つ。この小数2桁目は公式計測値ではない。
- 15番マイユニバースは公式結果「競走中止」。最後の採用点108.4秒の1.5秒後にモデルを非表示にする。これは表示上の処理で、中止時刻・地点を意味しない。完走扱いにしない。

## コースと共通エンジン

JRAの当該開催馬場概要でBコース使用を確認。一周1713.2m、直線359.1m、幅20〜25m、高低差1.9mの公開制約からコースを復元した。
2200mの発走用直線を内回り4角出口の外に延ばし、スタンド前を2回通る。最後の上りは初回にも通過する。
曲線は寸法に合わせた復元形で、実際のコースの測量データではない。ゴール柱も模式モデル。

`core/tracking-replay.js` が時刻に応じた各馬の進行距離・レーンを返し、共通の `renderer.js` が描く。
既存予想レースの抽選、配点、馬群モデルは宝塚記念のリプレイには使わない。

## 再現

元動画は著作権のある映像のためリポジトリに含めない。JSONには元動画のSHA-256を記録する。

```sh
python -m pip install numpy opencv-python-headless==4.12.0.88
python race-engine/tools/extract-takarazuka.py --video /path/to/official-854x480.mp4
node race-engine/tests/takarazuka-2026.mjs
PLAYWRIGHT_ENTRY=/path/to/playwright/index.mjs node race-engine/tests/takarazuka-browser.mjs
```

ブラウザ検査は390/430/1280px、実際のWebGLモデル、5カット、隊列18頭、停止・再開・巻き戻し・ゴール、固定の公式上位3頭を検査する。
静的検査では全軌跡の距離単調性、有限座標、完走時刻、DNF、2200mのコース長、初回・最終回ゴールの一致を確認する。
