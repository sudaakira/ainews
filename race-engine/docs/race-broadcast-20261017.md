# レース画面 v10 / 2026-10-17

## 今回の指定を優先する

1. スタートは走行方向の横から。全馬が画面内に入る構図。
2. 2コーナーで先頭集団へ寄る。
3. 3コーナーから俯瞰に切り替え、馬群全体を見せる。
4. 直線は走行方向と水平面で直交する真横のカメラ。ゴール直前に固定し、同じ画角で走り抜けを見せる。
5. ゴールで馬も脚も停止させない。3回の自動フリーズと結果専用カメラを廃止。
6. ゴール板と補助ポールはカメラと反対側のラチ外のみ。近側ポールなし。板の正面が横カメラに向く。
7. 『ダービースタリオン2』Switch 2版の公式に示されたセル調3Dを参考に、独自メッシュ、配色、UIで再構成。ゲーム本体の画像・ロゴ・音声は含めない。

## 実装

- `race-shotlist.js`: 4カット、純粋なカメラ座標計算。京都2000mは実装済みの模式コースの2角入口・3角入口・4角出口を探して切り替える。実測コースを新たに作ったものではない。
- `race-playback.js`: ゴール後の進行、全頭の通過検知、画面外へ走り抜ける終了時刻。順位は既存の `LIVE.rank` のまま。走り抜け中は最大2倍速で、実際の速度をHUDに表示する。
- `app.js`: 再生時計を勝馬ゴール時刻より先へ進める。一時停止、再開、新レース、シークを維持。3着通過後に確定順位を表示。
- `renderer.js`: ゴールから接線方向へ走路・ラチ・馬の位置を延長。4カット間だけ直接切替、同じカット内は平滑追従。ゴールで脚の時計を止めない。
- `kyoto-goal-board.js`: ゴール板の設置側と向きを修正。手前のゴールポールを削除。
- `horse-anime.js`, `chibi-gallop.js`: 馬の体形、脚、顔、陰影、騎手のゴーグル、走行周期を調整。枠色とゼッケンを維持。
- `race-cinematics.js/.css`: 明るい芝、独自セル調3D、白系スタンド、緑とクリームの放送UI。発光軌跡や紙吹雪、大きな中央テロップを廃止。全馬の枠色つき隊列表示、残距離、実再生速度、端の着順表示。

予想入力、14項目配点、馬の評価、モンテカルロ、乱数生成は変更しない。走り抜けの間隔は演出用で、実レースのタイム差ではない。

## 検証

`node race-engine/tests/smoke.mjs`

固定シードの全レース再現性、4カットの境界、横カメラの直交、固定ゴールカメラ、3〜18頭の走り抜け単調性、全頭退出と着順の整合性を確認。

GitHub Actions の `mobile-browser.mjs` は本番と同じ静的出力とThree.jsを使い、390/320/430pxのスマートフォン画面と1280pxのPC画面でWebGLを起動する。4カット、全馬の画面内配置、ゴール板の奥行きと可視性、ゴール後の全馬移動と脚の時計、手動停止/再開/やり直し、確定順位を確認。各カットをスクリーンショットへ保存する。
