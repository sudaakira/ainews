# 写真基準のサラブレッド馬体 v24

ユーザー提供の立ち姿（IMG_3067）と、青紫の5番ゼッケンの走行写真
（IMG_3069）を造形・馬装の目視基準にした。写真そのものは配布しない。

## 馬体

- CC0 Quaternius の既存リグに連続した新しい表面を構築。書き出し時に
  分離された頂点を接続し、スキンウェイトも補間する Loop 細分割を2段行う。
  元の1,744三角形から27,904三角形、14,133頂点。全出走馬で共有する。
- メートル単位の造形フィールドで、深い胸、斜めの肩甲部、上腕部、
  丸い臀筋、締まる脇腹、き甲、細い頸、頬と下脚関節を再構成。
  球体や円柱の筋肉パーツを貼り付ける方法ではない。
- つやのある短毛を低い粗さ・クリアコートと共有の空の反射光で表現。
  体色は芦毛、鹿毛、栗毛の区別を残し、茶系の彩度を抑えた。
- 固形の尾とたてがみを、先細りする64束の尾毛と26束のたてがみに交換。
  元の Tail/Neck ボーンのみで変形し、走行とは別の動きは追加していない。

## ゼッケン

- 長さ0.77 m、裾の基準高1.20 m。写真のように肩の後方から胴の中央へ
  掛かる小型の鞍下ゼッケン。前寄りの鐙、薄い鞍、腹帯の配置は維持。
- 青紫 `#29209b`、白い太字番号、下段の白い馬名。数字を露出する側面の
  中央へ置き、胴の曲面の角度ではなく鉛直位置に基づく UV で縦伸びを防ぐ。
- 数字の高さ約0.24 mを基準に調整。写真の印刷書体は特定できないため、
  字形・太さを近似した Noto Sans CJK JP Bold のサブセットを同梱し、
  端末による字体の変化を防ぐ。元フォントの出典は
  https://github.com/notofonts/noto-cjk/tree/main/Sans 、SIL OFL 1.1。
  ライセンス全文は assets/models/Noto-CJK-OFL.txt。
- 照明・遠近・布の変形があるため、写真とのピクセル単位の同一性や
  元書体との完全一致を主張するものではない。

## 維持・検証

`horse-sprint-v19.glb`、`sprint-motion-v19.json`、gallop 更新処理、
骨格とアニメーションチャンネルを変更しない。予想・乱数・着順・カメラも
変更しない。最新版の5カット構成と4Cのパンを引き継ぐ。

検証ページは本編と同じモデルを使い、走行に加えて「立ち姿」「馬体のみ」も
表示できる。左右手前・4方向・6位相の48描画、接地、布と腿の干渉、
騎手と鞍の連結を検査する。検査の合格だけでなく描画結果を目視する。

変更前の main (4f0a66e) でも smoke の4C検査が失敗することを再現した。
先頭馬の投影 x=0.125049... が要求する中央寄り15%の範囲を外れる。
検査を緩和せず、カメラ実装・レンズ・パンも変更していない。
ユーザーの追加承認により、この既存不具合も修正した。v27 はカメラ位置、
5カット、18–23度の単調なズームを維持し、先頭馬と5頭の重心との角度差だけを
画面比に応じた滑らかな tanh 関数で抑える。急なクランプや視点の移動はない。
既存のテスト閾値は維持し、4画面比×151時刻のパン・先頭馬の可視性を追加検証する。

### 初期化の高速化 v24.1

高密度化した馬体全体へ数千回の交差検査をすると初期の鞍・布の生成が遅い。
全てのフィッティング用レイが一定の Z 平面内にあることを利用し、元の三角形を
Z の96区間へ分類した。近似形状に置き換えず、元の頂点 ID と三角形の順序を
保ったまま交差候補だけを絞る。計測は18.750秒から193.301ミリ秒へ短縮。
鞍・布・裏地・縁取りの全頂点属性とインデックスの SHA-256 は前後とも
`eb6dc03321272f0904ce716eba1e7a814a6da505d3ef8e8ffb454b15a708a474`。
表示とスキンウェイトはビット単位で同一。計測値は実行環境に依存する。
